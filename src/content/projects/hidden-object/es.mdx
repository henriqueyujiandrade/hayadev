## Sobre el proyecto

Onde estou? («¿Dónde estoy?») es un juego terapéutico de búsqueda visual en el que
el jugador busca objetos en un escenario ilustrado.

La experiencia combina búsqueda visual, interacción táctil y biofeedback
respiratorio, utilizando datos de un sensor de frecuencia cardíaca para influir
en la dinámica de la partida.

El juego se desarrolló para ejecutarse en el navegador y está integrado en la
plataforma terapéutica de Self.

## Principales desafíos técnicos

- Desarrollo de una experiencia interactiva con **Canvas**.
- Generación procedural de las posiciones de los objetos respetando reglas de
  composición visual.
- Sistema de perspectiva para posicionar y dimensionar los elementos.
- Control de dificultad basado en las características visuales del escenario.
- Partidas reproducibles mediante generación pseudoaleatoria determinista.
- Interacción optimizada para dispositivos con pantalla táctil.
- Gestión del zoom y del desplazamiento en escenarios de gran tamaño.
- Integración con **Web Bluetooth** para recibir datos fisiológicos.
- Procesamiento de biofeedback en tiempo real.
- Funcionamiento con o sin sensor conectado.
- Integración del juego con el portal de la plataforma.

## Herramientas de autoría

Además del juego, desarrollé herramientas internas para facilitar la creación y
el mantenimiento de los escenarios.

El editor permite posicionar y redimensionar elementos, configurar propiedades
del escenario, validar la composición y ejecutar partidas de prueba.

Esto convierte parte de la creación de contenido en datos configurables y reduce
la necesidad de cambios manuales en el código para cada nuevo escenario.

## Arquitectura

La escena principal se renderiza con **Canvas**, mientras que React gestiona la
interfaz alrededor del juego, como los menús, el HUD y las pantallas auxiliares.

La lógica del juego se separó del renderizado para facilitar el mantenimiento y
permitir que las reglas de generación, dificultad e interacción evolucionen de
forma independiente.

## Biofeedback

El juego puede recibir datos de un sensor de frecuencia cardíaca mediante **Web
Bluetooth** o a través de la plataforma que aloja la experiencia.

Los datos fisiológicos se procesan para generar un nivel de biofeedback que se
utiliza durante la partida.

Cuando el sensor no está disponible, el juego tiene un modo alternativo que
mantiene la experiencia funcionando.

## Lo que demuestra este proyecto

Este proyecto combina **desarrollo de juegos, generación procedural, Canvas,
herramientas de autoría, interacción táctil, procesamiento fisiológico e
integración con hardware Bluetooth**.

El principal desafío fue crear partidas variadas y reproducibles sin perder el
control sobre la composición visual y la experiencia del jugador.
