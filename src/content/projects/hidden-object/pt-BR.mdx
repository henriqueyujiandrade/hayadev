## Sobre o projeto

Onde estou? é um jogo terapêutico de busca visual no qual o jogador procura
objetos em um cenário ilustrado.

A experiência combina busca visual, interação por toque e biofeedback
respiratório, utilizando dados de um sensor de frequência cardíaca para
influenciar a dinâmica da partida.

O jogo foi desenvolvido para ser executado no navegador e integrado à plataforma
terapêutica da Self.

## Principais desafios técnicos

- Desenvolvimento de uma experiência interativa utilizando **Canvas**.
- Geração procedural de posições de objetos mantendo regras de composição visual.
- Sistema de perspectiva para posicionamento e dimensionamento dos elementos.
- Controle de dificuldade baseado nas características visuais do cenário.
- Partidas reproduzíveis por meio de geração pseudoaleatória determinística.
- Interação otimizada para dispositivos com tela sensível ao toque.
- Tratamento de zoom e movimentação de cenários de grande dimensão.
- Integração com **Web Bluetooth** para receber dados fisiológicos.
- Processamento de biofeedback em tempo real.
- Funcionamento com ou sem sensor conectado.
- Integração do jogo com o portal da plataforma.

## Ferramentas de autoria

Além do jogo, desenvolvi ferramentas internas para facilitar a criação e
manutenção dos cenários.

O editor permite posicionar e redimensionar elementos, configurar propriedades do
cenário, validar a composição e executar partidas de prévia.

Isso transforma parte da criação do conteúdo em dados configuráveis, reduzindo a
necessidade de alterações manuais no código a cada novo cenário.

## Arquitetura

A cena principal é renderizada utilizando **Canvas**, enquanto React gerencia a
interface ao redor do jogo, como menus, HUD e telas auxiliares.

A lógica do jogo foi separada da renderização para facilitar a manutenção e
permitir que as regras de geração, dificuldade e interação evoluam de forma
independente.

## Biofeedback

O jogo pode receber dados de um sensor de frequência cardíaca através de **Web
Bluetooth** ou pela plataforma que hospeda a experiência.

Os dados fisiológicos são processados para gerar um nível de biofeedback
utilizado durante a partida.

Quando o sensor não está disponível, o jogo possui um modo alternativo para
manter a experiência funcional.

## O que este projeto demonstra

Este projeto combina **desenvolvimento de jogos, geração procedural, Canvas,
ferramentas de autoria, interação touch, processamento fisiológico e integração
com hardware Bluetooth**.

O principal desafio foi criar partidas variadas e reproduzíveis sem perder o
controle sobre a composição visual e a experiência do jogador.
