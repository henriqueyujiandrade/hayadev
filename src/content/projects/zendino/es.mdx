## Sobre el proyecto

Zendino es un juego de biofeedback respiratorio en el que el niño interactúa con
un dinosaurio mientras sigue un ejercicio de respiración guiada.

El juego utiliza animaciones y elementos del escenario como feedback visual para
hacer la actividad más intuitiva y mantener la experiencia adecuada al público
infantil.

Desarrollé la lógica del juego, el sistema de animación, la integración con un
sensor de frecuencia cardíaca y la comunicación con la plataforma que ejecuta las
sesiones.

## Principales desafíos técnicos

- Desarrollo de una experiencia interactiva con **Canvas**.
- Animaciones sincronizadas con el ciclo respiratorio.
- Integración con sensores de frecuencia cardíaca mediante **Web Bluetooth**.
- Procesamiento de datos fisiológicos en el navegador.
- Distintos niveles de dificultad para el biofeedback.
- Funcionamiento con o sin sensor conectado.
- Gestión de la pérdida de conexión sin interrumpir la experiencia.
- Sistema de estados para controlar las distintas etapas de la partida.
- Renderizado optimizado para mantener una experiencia fluida.
- Tutorial que reutiliza los mismos componentes y la lógica de renderizado del
  juego.

## Arquitectura

La lógica del juego se separó de la capa de renderizado, lo que permite probar
las reglas de comportamiento de forma independiente de los elementos visuales.

El bucle de animación usa Canvas para controlar el renderizado fotograma a
fotograma, mientras que React se encarga de la estructura de la aplicación y de
la gestión de los estados de alto nivel.

La experiencia también se desarrolló para distintos tamaños de pantalla,
manteniendo proporciones y posicionamiento coherentes.

## Biofeedback

El juego puede recibir datos de un sensor de frecuencia cardíaca mediante **Web
Bluetooth**.

Los intervalos entre latidos se procesan en el navegador y se utilizan para
generar un indicador de biofeedback que influye en el comportamiento del
personaje.

Cuando el sensor no está disponible o se interrumpe la conexión, el juego tiene un
comportamiento alternativo que mantiene la sesión en marcha.

## Lo que demuestra este proyecto

Este proyecto combina **desarrollo de juegos, frontend, animación, procesamiento
de datos fisiológicos e integración con hardware Bluetooth**.

Más que implementar una interfaz interactiva, el desafío fue convertir reglas de
biofeedback en una experiencia visual sencilla y comprensible para niños.
