## Sobre o projeto

Zendino é um jogo de biofeedback respiratório no qual a criança interage com um
dinossauro enquanto acompanha um exercício de respiração guiada.

O jogo utiliza animações e elementos do cenário como feedback visual para tornar
a atividade mais intuitiva e manter a experiência adequada ao público infantil.

Desenvolvi a lógica do jogo, o sistema de animação, a integração com sensor de
frequência cardíaca e a comunicação com a plataforma que executa as sessões.

## Principais desafios técnicos

- Desenvolvimento de uma experiência interativa utilizando **Canvas**.
- Implementação de animações sincronizadas com o ciclo respiratório.
- Integração com sensores de frequência cardíaca utilizando **Web Bluetooth**.
- Processamento de dados fisiológicos no navegador.
- Implementação de diferentes níveis de dificuldade para o biofeedback.
- Funcionamento com ou sem sensor conectado.
- Tratamento de perda de conexão sem interromper a experiência.
- Sistema de estados para controlar as diferentes etapas da partida.
- Renderização otimizada para manter uma experiência fluida.
- Tutorial utilizando os mesmos componentes e lógica de renderização do jogo.

## Arquitetura

A lógica do jogo foi separada da camada de renderização, permitindo testar as
regras de comportamento independentemente dos elementos visuais.

O loop de animação utiliza Canvas para controlar a renderização quadro a quadro,
enquanto o React permanece responsável pela estrutura da aplicação e
gerenciamento dos estados de alto nível.

A experiência também foi desenvolvida para diferentes tamanhos de tela, mantendo
proporção e posicionamento consistentes.

## Biofeedback

O jogo pode receber dados de um sensor de frequência cardíaca através de **Web
Bluetooth**.

Os intervalos entre batimentos são processados no navegador e utilizados para
gerar um indicador de biofeedback que influencia o comportamento do personagem.

Quando o sensor não está disponível ou ocorre uma interrupção na conexão, o jogo
possui um comportamento alternativo para manter a sessão funcionando.

## O que este projeto demonstra

Este projeto combina **desenvolvimento de jogos, frontend, animação,
processamento de dados fisiológicos e integração com hardware Bluetooth**.

Mais do que implementar uma interface interativa, o desafio foi transformar
regras de biofeedback em uma experiência visual simples e compreensível para
crianças.
